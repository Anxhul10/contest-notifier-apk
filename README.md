# Contest Notifier

Contest Notifier is an Android app that helps you keep track of upcoming coding contests and reminds you before they start, so you don't miss them.

The app brings contest information from different competitive programming platforms into one place.

## Features

- **Upcoming Contests:** View upcoming coding contests in one place.
- **Notifications:** Get reminders before a contest starts.
- **Dark Mode:** Use the app with a dark interface.
- **Light Mode:** Switch to a light interface.
- **Simple Interface:** Browse contest information in an easy-to-understand layout.

> [!NOTE]
> Contest Notifier fetches contest information whenever you open the app and schedules reminders locally on your device. It does not rely on a server continuously monitoring contests or sending push notifications.
>
> **Please open the app at least once a day** to refresh contest information and keep your upcoming contest reminders up to date.
