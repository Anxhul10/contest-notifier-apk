# Privacy Policy – Contest Notifier

**Effective Date:** November 6, 2026

Contest Notifier ("the App") is an Android application that helps users discover upcoming competitive programming contests and receive reminders before they begin.

This Privacy Policy explains how the application handles information when you use it.

## 1. Information We Collect

Contest Notifier does not require users to create an account or provide personal information to use its core features.

The application does not intentionally collect:
- Names or personal profiles.
- Email addresses.
- Phone numbers.
- Location information.
- Payment information.

## 2. Contest Information

The application retrieves publicly available contest information from supported competitive programming platforms, including:

- Codeforces
- LeetCode
- CodeChef

Contest information is retrieved through the application's backend service and displayed within the application.

## 3. Local Data Storage

Contest Notifier uses Android Room Database to store contest information locally on your device.

This allows the application to:
- Load previously fetched contest information.
- Reduce unnecessary network requests.
- Access cached contest data when an internet connection is unavailable.

This cached information remains on your device unless it is cleared or the application data is removed.

## 4. Notifications and Permissions

The application schedules local notifications to remind users about upcoming contests.

Depending on your device and Android version, the application may request permissions for:
- Sending notifications.
- Scheduling exact alarms.
- Running scheduled reminders.

Contest Notifier uses these permissions to deliver contest reminders, including notifications one hour and ten minutes before a contest starts.

Notifications are scheduled locally on your device. The application does not require a continuously running push notification service to deliver these reminders.

## 5. Network Requests and Third-Party Services

The application communicates with its backend service to retrieve contest information.

It also checks GitHub Releases to determine whether a newer application version is available.

These services may process technical information associated with network requests, such as IP addresses and request metadata, according to their respective privacy policies and logging practices.

The application does not intentionally transmit personal profile information to these services.

## 6. Data Sharing

Contest Notifier does not sell users' personal information.

The application does not intentionally share personal information with advertisers or data brokers.

Technical information may be processed by hosting providers and third-party services involved in delivering the application's functionality.

## 7. Data Security

Reasonable measures are used to protect the application's backend and associated services.

Contest information stored locally is managed through Android's application storage mechanisms.

However, no method of electronic storage or internet transmission can guarantee absolute security.

## 8. Children's Privacy

Contest Notifier is a general-purpose application and does not knowingly collect personal information from children.

## 9. Changes to This Privacy Policy

This Privacy Policy may be updated when application functionality or data handling practices change.

Any updated version will be published on this page.

Users are encouraged to review this policy periodically.
